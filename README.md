# inventory-manager
Order &amp; Inventory Management System — Python CLI tool
Order & Inventory Management System

A Python command-line tool for managing orders and stock levels,
developed to automate reporting tasks in a manufacturing/distribution environment.

## Features
- Real-time inventory status with low-stock alerts
- Order tracking by status (Pending / In Progress / Delivered)
- Projected inventory calculation based on active orders
- Automatic CSV report export

## How to run
python order_manager.py

## Background
Built as a personal project to apply Python skills (CS50P) to a real
business problem — automating manual spreadsheet work in order and
inventory management.
